# Whale Tracking Analysis Checklist

## Phase 1: Data Collection
- [ ] Identify wallet clusters
- [ ] Track transaction history (30-day minimum)
- [ ] Monitor exchange inflows/outflows
- [ ] Check collateral positions (DeFi)

## Phase 2: Pattern Recognition
- [ ] Accumulation vs distribution phase
- [ ] Timing relative to market sentiment
- [ ] Cross-asset correlation

## Phase 3: Validation
- [ ] Multiple source confirmation
- [ ] Historical pattern matching
- [ ] Sentiment alignment check

## Phase 4: Synthesis
- [ ] What is the likely intent?
- [ ] What is the timeframe?
- [ ] What is the risk assessment?
